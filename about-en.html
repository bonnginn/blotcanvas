Prepare Western blot figures and source records

BlotCanvas is a free browser application for preparing publication and presentation figures, source-image records and preliminary quantification from Western blot images. Images are processed in your browser and are not sent to an application server. It is Public Beta software released under the MIT License.

From image import to saved output

  1. Import acquisition files and confirm the Signal, Merge and Marker roles.
  2. Correct rotation for each gel, define crop regions, and place molecular-weight markers and lane-condition labels.
  3. Review the figure and save an editable PDF or PNG / TIFF / JPEG / PDF, a Source record showing original images and crop positions, and a lightweight project JSON.
  4. Only when needed, place band and background ROIs for preliminary quantification and export graphs or measurement CSV.

Keep original images separate from display adjustments

Keep an independent backup of original images. Use the same display adjustments for comparable images probed with the same antibody, and retain the processing history. Figure inversion, brightness and contrast affect display only; quantitative values are calculated from the original image before display adjustment.

Project JSON does not embed the images. To resume, open the JSON and choose the source-image folder to relink.

Beta limitations

Use a current version of Chrome or Edge. Preliminary quantification is a beta rectangular-ROI method. Before using results in publications, validate the same image and ROIs against ImageJ or another established method. Statistical analysis and aggregation of independent biological replicates are outside the current scope.

Follow institutional, journal and research-integrity rules. Do not send original images, unpublished data, personal or patient information, or other confidential information in problem reports.
