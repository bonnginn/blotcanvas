Before you start

  • Keep an independent copy of every original image.
  • Use a current version of Chrome or Edge.
  • Save a lightweight project JSON periodically and keep it with the source-image folder.
  • Figure display adjustments and quantitative measurements are separate.

Development and feedback

BlotCanvas is created and improved using OpenAI Codex as a development tool. The developer reviews reports submitted through the Google form and may provide their text to Codex to organize the problem, investigate causes and prepare fixes.

Reports are not implemented automatically. The developer decides which changes to make after considering necessity, scientific validity, priority and effects on existing features.

Do not enter or attach original Western blot images, unpublished data, personal or patient information, or other confidential information in the form.

1. Import acquisition files

Choose the imaging system, then select a folder or image files. ATTO LuminoGraph files are classified from their names; assign image roles manually for other systems. Unneeded acquisition sets can be removed from the list.

If the system does not produce a Merge image, select signal and bright-field / marker images to generate a working Merge. Only images with matching pixel dimensions can be overlaid. Original files and quantitative images remain unchanged.

2. Correct rotation

Place a horizontal guide near a marker band and adjust the angle for each gel. Check each gel and acquisition separately.

3. Define crop regions

Drag the corners to resize and the center to move a region. Width or height can be synchronized among images in the same figure. Define a separate region for a loading control in the same image.

4. Adjust the figure display

Invert the image and adjust brightness or contrast. Apply the same settings to comparable images probed with the same antibody, and retain the originals and processing records.

These adjustments affect display only. Quantitative values are calculated from the original image before display adjustment.

5. Place molecular-weight markers

Select the marker product and molecular weights to display, then click their positions on the full image from top to bottom. Check each gel separately.

6. Create lane conditions

Choose the lane count and condition format. Condition rows can be reordered and copied to another gel.

Use Figure Preview to adjust labels, antibody names, positions and fonts.

7. Review and save the figure

  • Editable PDF: Edit text, lines and frames in Illustrator. Choose the physical placement width for a publication figure (25.5, 39 or 54 mm).
  • PNG / TIFF / JPEG / PDF: Save the finished figure as one file.
  • Source record: Record original images and crop positions.
  • Project JSON: A lightweight file without embedded images. To resume, open the JSON and choose the source-image folder to relink.

For Illustrator editing, prefer the more reliably compatible editable PDF. Browser security requires selecting the source folder when relinking, even if the JSON and images are stored together.

8. Preliminary quantification

Align a rectangular ROI with each lane’s band and place a background ROI in an area without bands. For loading-control normalization, choose a blot from the same gel.

Caution: This is a beta rectangular-ROI method. Before using results in publications, validate the same image and ROIs against ImageJ or another established method.

9. Graph and save results

Build the X axis from the condition table and adjust colors, fonts, size and title. In addition to saving the current graph, graphs for the same antibody from Gel 1 and Gel 2 can be stacked vertically, with gel names, in one PNG. Editable PDF and transparent graph PNG output support physical placement widths of 25.5, 39 or 54 mm for publication figures. Measurement CSV can also be saved. Statistical analysis and aggregation of independent biological replicates are outside the current scope.

Resume a project

Choose the project JSON with Open at the top of the app. Images are not embedded in the JSON; reselect the original images if needed.

Troubleshooting

Use Report a problem / improvement at the top of the app to send reproduction steps. Do not send patient information, unpublished images, experiment-specific condition names or other unnecessary confidential information.

BlotCanvas is beta software. Follow institutional, journal and research-integrity rules, and retain original images and processing records.
