# BlotCanvas 公開前チェックリスト

大規模な新機能は、次の確認を終えてから公開ベータ版へ反映します。軽微な文言・表示修正は、既存機能を壊さないことを確認して随時公開できます。

## 機能バックテスト

- 複数の実画像シリーズで主要操作を完走できる
- 複数撮影、複数ゲル、複数抗体で確認する
- プロジェクトJSONの保存・再読込を確認する
- 出力SVG・CSVの内容を参照ソフトウェアと比較する
- エラー時にデータを失わず、利用者が原因を理解できる

## 定量化の追加確認

- 同一ROIについてImageJのArea、Mean、Integrated densityと比較する
- 16-bit TIFFの画素値が元画像から読み取られていることを確認する
- 回転なし・回転ありで座標変換を確認する
- 局所背景、正規化、飽和画素率を既知データで確認する
- 複数のローディングコントロール候補でレーン対応を確認する

## ブラウザ互換性

- 最新版Google Chrome
- 最新版Microsoft Edge
- 実機の最新版Safari（macOS）
- SafariでTIFF読込、フォルダ読込、ROI操作、測定、JSON・SVG・CSV保存を確認する
- PWAとして追加した場合も主要操作を確認する

## 公開手順

1. ローカル開発版で上記項目を確認する
2. バージョン履歴を更新する
3. Pull Requestで公開用静的ファイルとの差分を確認する
4. GitHub Pagesへ反映する
5. 公開URLでキャッシュ更新後の表示と主要操作を再確認する
